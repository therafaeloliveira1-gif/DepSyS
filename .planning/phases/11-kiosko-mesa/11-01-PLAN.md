# Plan 11-01: Rediseño Kiosko Industrial de la Terminal de Mesa (Empaque)

## Objetivo
Transformar la terminal de mesa en un entorno de Kiosko Industrial ergonómico de alta velocidad:
1. Eliminar distracciones visuales, barras de supervisor y márgenes desperdiciados cuando el usuario es un Guardador de Mesa.
2. Escala tipográfica gigante para lectura a 2 metros (SKU en 24px+, cantidad de piezas en 36px+ bold con badges de alto contraste).
3. Eliminación total del botón "Marcar Todos" para forzar la validación física de cada repuesto.
4. Soporte para pistola de código de barras USB/HID con listener global ininterrumpido (captura bips sin requerir foco de cursor).
5. Feedback acústico nativo con Web Audio API (bip agudo 1200Hz para SKU OK, buzzer grave 220Hz para error o repuesto ajeno).
6. Barra de progreso industrial en tiempo real (X / Y piezas empacadas) y botón de cierre con atajo Enter.
