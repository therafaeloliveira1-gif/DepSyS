La Cadena Operativa en 6 Eslabones Claros
Detalle exacto de la lógica de negocio
01

1. Vendedor genera el Pedido en App Venta

El cliente en el salón solicita repuestos. El vendedor carga los códigos en la App de Ventas y presiona confirmar. La app hace un HTTP POST a la API Apache (PHP) en el servidor 192.168.1.125.

App Venta ➔ API Apache Puerto 80 HTTP
02

2. La API registra el Pedido en MySQL

La API de Apache valida el pedido e inserta los registros en tbl_notas_deposito y tbl_nota_items de la base de datos mendes_db con estado "Pendiente de Asignar".

API ➔ MySQL mendes_db Puerto 3306 Local
03

3. DepSyS verifica y el Supervisor Asigna a Picking

En la pantalla central de DepSyS (Supervisor) se detecta el nuevo pedido en tiempo real. El usuario supervisor asigna la nota al recolector disponible (o mediante regla automática de asignación).

DepSyS Central Función de Asignación
04

4. Recolector ejecuta Picking con escáner láser

El operador asignado abre la App Picking en su colector móvil. La app le indica qué pasillo y estante visitar. El operador escanea con el láser cada pieza, evitando errores de código. Al terminar, lleva el canasto a la Mesa.

App Picking Móvil Separación Física
05

5. Vuelve a DepSyS: El Apartado de Mesas audita y confirma

En la PC de la Mesa de Control de DepSyS, el guardador de mesa audita pieza por pieza contra la pantalla. Cuando todo está correcto, presiona "Confirmar Pedido". Este botón desbloquea la salida final.

DepSyS Mesas Auditoría Aprobada
06

6. Bifurcación Final: DepSyS SIFEN (Factura) + App-Envios (Despacho)

• Hacia DepSyS SIFEN: Genera el XML v150, firma con CODE100 Don Elias, envía a la SET, recibe aprobación (0200), imprime el KuDE con QR y notifica la venta a SAP (/api/ventas).
• Hacia App-Envios: El paquete aparece en la cola de despacho de expedición para asignarle chofer, transportadora y control de flete.

SIFEN + Envíos + SAP Circuito Cerrado
